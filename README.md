# Aerion Active

A responsive sportswear storefront built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Included functionality

- Responsive product catalogue
- Search, filtering and sorting
- Product detail modal with color and size selection
- Persistent shopping bag using local storage
- Quantity controls and checkout flow
- Newsletter interaction
- Local SVG product and editorial artwork
- No build step or external dependencies
